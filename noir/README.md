# NOIR — Streetwear

SPA em React, TypeScript, Tailwind CSS e Vinext. Catálogo ilustrativo com filtros de categoria, estado global por Context, carrinho lateral acessível e checkout demonstrativo sem cobranças.

## Executar
npm ci
npm run dev

## Compilar
npm run build

O catálogo fica em app/products.ts; a vitrine em app/page.tsx; estado e drawer em app/store.tsx. O carrinho dura durante a sessão da página. Não há serviço de pagamentos ou pedidos conectado.

Fotografias ilustrativas: Unsplash, Bùi Hoàng Long (hero e moletom), Luis Quintero, DJ Tears PLK, Jason Leung, CHUTTERSNAP e Joel Mott. As fotos não representam estoque real.
